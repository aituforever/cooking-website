Movie Website is a fun, full-stack web application I built as a personal project to explore building REST APIs in Go and creating responsive front-end designs with HTML, CSS, and Bootstrap 5.

## Features

- **REST API in Go:** Serves movie data for the front-end.
- **Responsive Front-End:** Built using HTML, CSS, and Bootstrap 5 for a modern look.
- **Testing:** Includes unit tests, integration tests, and E2E tests.
- **Hosting:** Used Ngrok to securely expose the local server for testing and demos.
- **Collaboration:** Managed source code using Git with contributions from a few friends.

## Tech Stack

- **Back-End:** Go
- **Front-End:** HTML, CSS, Bootstrap 5, JavaScript
- **Tools:** Ngrok, Git, TravisCI (for CI/CD testing)
